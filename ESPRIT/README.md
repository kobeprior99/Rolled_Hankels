# ESPRIT Using Hankel Methods

This directory investigates the application of Hankel matrix methods to **Estimation of Signal Parameters via Rotational Invariance Techniques (ESPRIT)** for spectral estimation.

The objective is to explore how Hankel matrix construction and low-rank signal subspace representations can be leveraged to estimate the frequencies of closely spaced sinusoids.

Areas of investigation include:
- Constructing Hankel matrices from sampled signals.
- Extracting signal subspaces using Singular Value Decomposition (SVD).
- Applying rotational invariance to estimate sinusoidal frequencies.
- Evaluating performance under varying SNR, sampling rates, frequency separation, and sample counts.

The primary goal is to assess whether Hankel-based formulations offeruseful spectral analysis
